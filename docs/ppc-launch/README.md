## 市場・検索意図の観測

検索結果とサジェストでは、`運送業 融資`、`運送業 資金繰り`、`運送業 運転資金`、`運送業 資金調達`、`運送業 燃料費` が独立した検索の起点として観測できた。運送業の資金繰りでは、売掛金入金までの期間、燃料費、人件費・高速代、車両整備などの支出が論点になる。一方でこの周辺にはファクタリングの検索結果が多く、融資の申込意図ではない流入を混ぜやすい。

初回は「資金繰りの情報収集」より一段深い、**業種＋融資手段** の語だけを採る。燃料費・車両修理は需要の筋としては自然だが、検索ボリュームとCPCの実測がないため低額の発掘枠に隔離する。

## 推奨する初期構成

```text
CP01_アクトウィル_運送業法人融資_手動CPC
├─ AG01_コア融資_完全一致        : S（8語、上限55〜70円）
└─ AG02_状況発掘_フレーズ一致    : A（7語、上限40〜45円）
```

- 入札はすべて個別CPC（手動）。自動入札・インテント/部分一致は使わない。
- 入札額は**予測CPCではなく、低く始めるための上限**。キーワードプランナーの予測値は、アカウント側の広告ブロッカーによりこの調査では取得できなかった。
- 表示が出ない語は、同じ語を上げ続けない。1回だけ `+10円` を試し、それでも表示がなければフレーズ一致の近接語で検索語句を回収する。
- 初回に1KW1CPへ分離しない。仮審査完了またはLP CTAの質が良い語だけを、後から完全一致の単KW枠へ昇格する。

## 初期に入れない語

|区分|語・テーマ|理由|
|---|---|---|
|競合が強く意図が広い|事業資金融資、法人融資、ビジネスローン、即日融資|運送業への限定がなく、CPC高騰と対象外流入を招く。|
|別サービス|ファクタリング、売掛債権買取|本案件は融資。LPの説明なしで混ぜると期待と着地がずれる。|
|規制確認が先|運送業 借入 一本化、運送業 債務整理|LPには一本化の言及があるが、債務関連広告の扱いと広告主の許可を確認してから別枠で検証する。|
|低品質・対象外|個人事業主、軽貨物 個人、審査なし、ブラック、闇金|法人限定・否認条件・広告審査の観点で初期対象にしない。|
|情報収集|資金繰り表、燃料費 割合、勘定科目、助成金|申込までの距離が遠い。|

## 出稿前の必須確認

1. ASPへ、禁止される「社名・サービス名」の正式な語一覧（表記ゆれ、英字、競合名を含む）を確認する。
2. 広告掲載面のPR/広告表記を、公開する記事LPのファーストビューで確認する。A8の案内上、公開後に掲載URLの提出も必要。
3. `借入一本化` のキーワード・広告文使用可否を広告主／ASPへ確認する。初回は未使用。
4. Google広告アカウントに金融サービスの適格性確認タスクが出ていないか確認する。アフィリエイトは、対象地域で適格性確認が必要な場合に「承認済み第三者」としての手続きが必要になることがある。
5. LP側で、広告クリック、記事LP到達、公式遷移クリック、仮審査完了（取得できる場合）、ASP発生、承認を別列で記録する。
