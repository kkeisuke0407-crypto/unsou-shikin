## 前提として反映した制約

[README.md](README.md) の「案件確認」で決めた方針を、そのまま広告文の制約に落とし込んでいる。

| 制約 | 反映内容 |
|---|---|
| リスティング制限が「社名・サービス名以外」 | **ブランド語を一切使用しない**。除外KWにも登録済み（[02_negative_keywords.txt](02_negative_keywords.txt)） |
| 登録表示は事実確認用。広告コピーでの権威付けには使わない | **東京都知事(5)第31521号を広告文に入れない** |
| 即日表現 | 速度訴求は「審査は最短60分」に一本化。「最短即日契約可能」「必ず即日」「審査なし」は不使用 |
| 担保・保証 | 「無担保」「無保証」と断定しない。「第三者保証人は原則不要」「不動産担保は原則不要」表記に統一 |
| 対象は法人 | 「法人限定」「法人向け」を各AGの見出し・説明文に配置し、対象外流入を入口で抑制 |
| 別サービスを混ぜない | 借入一本化を広告文に出さない。※競合グループ（AG03・AG05）では、比較文脈に限り「ファクタリング」の語を使用する |
| 競合名（商標） | **広告文に競合名を一切入れない。** キーワードとしての使用は原則可能だが、広告文に使うと商標権者の申し立てで不承認になる。詳細は [04_competitor_research.md](04_competitor_research.md) |

# 意図的に入れなかったもの

| 除外したもの | 理由 |
|---|---|
| ブランド語（自社の社名・サービス名） | ASPのリスティング制限。除外KWにも登録済み |
| 競合名（うんそうくん、ビートレーディング等） | **広告文に入れると商標権者の申し立てで不承認になる。** キーワードとしてのみ使用する |
| 「他社より安い」「No.1」等の比較優位 | 比較根拠がなく、景品表示法上も不可 |
| 東京都知事(5)第31521号 | READMEで「広告コピーでの権威付けには使わない」と決定済み |
| 「最短即日契約可能」 | 速度訴求は「審査は最短60分」に一本化するというREADMEの方針 |
| 「無担保」「無保証」 | 代表者の連帯保証が必要なため断定できない |
| 「低金利」 | 上限15.00%は元本100万円以上の利息制限法上限と同水準 |
| ファクタリング・売掛債権買取 | 除外KWに入れた手段。広告文に出すと意図のズレた流入を招く |
| 借入一本化 | 広告主／ASPの許可待ち |
| 構造化スニペット | 初回15語・2AGの規模では不要と判断。必要になれば追加する |

# 入稿時の設定メモ

- 見出しのピン留めは**グループによって方針を変える**。
  - `AG01` `AG02`：**ピン留めしない。** キーワード自体に「運送業」が入っており、業種のズレは起きない。アセットレポートを見てから判断する。
  - `AG03` `AG04` `AG05`：**位置1と位置2をピン留めする（必須）。** 競合名は全業種の事業者が検索するため、業種を明示しないと他業種のクリックを買い続けることになる。ピン留めで配信の最適化は多少制限されるが、**無駄クリックの抑制を優先する。**
- 表示URLパス案：AG01 `運送業` / `融資条件`、AG02 `運送業` / `資金調達`、AG03 `運送業` / `調達方法比較`、AG04 `法人向け` / `融資条件`、AG05 `運送業` / `手段を比較`
- **競合グループ（AG03〜AG05）の除外設定に注意。** `ファクタリング` `売掛債権買取` をキャンペーン単位で除外すると AG03・AG05 が配信されない。AG01・AG02 の広告グループ単位の除外として登録し直すこと（[04_competitor_research.md](04_competitor_research.md)）
- **競合指名は品質スコアが低くなりやすい。** ランディングページに競合名が含まれないため、設定した45〜70円では表示されない語が多いと見込まれる。表示ゼロの語は一度だけ +10円を試し、改善しなければ近接語に切り替える
- 広告は各AG 1本ずつから開始。A/Bは初期のインプレッションが分散するため、データが溜まってから。
- 公式サイトの貸付条件が変わった場合、**記事LPと広告文の両方**を更新する。片方だけ直すと不整合が生じる。
