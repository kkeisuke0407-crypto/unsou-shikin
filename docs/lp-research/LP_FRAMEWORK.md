# LP_FRAMEWORK — 記事LPの構成と各セクションの役割

- 作成日: 2026-08-05
- 対象: アクト・ウィル株式会社「運送事業向け資金融資」PPCアフィリエイト記事LP
- 遷移先: https://actwill.co.jp/lp5/unsou/a8/ （A8.net 経由。記事内の `[A8商品リンク]` を差し替える）
- 前提端末: スマートフォン主体（想定70〜85%）。**モバイルファーストで設計し、PCは中央1カラムを最大720pxで固定**
- 本書の使い方: 本書だけでLP実装の指示が完結するように記述している。本文の確定原稿は [ARTICLE_MASTER.md](ARTICLE_MASTER.md) を参照

## 0. 全体設計

### 0-1. 採用する型

**結論先出し型 × 判断支援型のハイブリッド**

```
[PR表記] → [FV：対象の明示] → [結論を3行で] → [CTA①]
  → [適合セルフチェック]
  → [運送業の資金繰り構造：データで納得させる]
  → [手段の比較：中立に整理] → [CTA②]
  → [広告主の実在性：公的データで実証]
  → [貸付条件の全開示：不利な情報も含む] → [CTA③]
  → [申込の流れ：次に何が起きるか]
  → [向き・不向き：正直に切る] → [CTA④]
  → [相談前チェックリスト]
  → [FAQ]
  → [まとめ] → [CTA⑤]
  → [出典・運営者情報・更新日]
```

### 0-2. 設計上の3原則

1. **結論を先延ばししない。** PPC流入者は結論のために来ている。第2セクションで答えを出し、その直下に最初のCTAを置く。
2. **不利な情報を先に出す。** 上限金利15.00%が法定上限と同水準であること、代表者連帯保証が必要なこと、遅延損害金が年率20.00%であることを隠さない。これが後半の信頼を作る。
3. **対象外の読者を丁寧に帰す。** 個人事業主・300万円未満・金利最優先の読者を無理に送らない。不適合遷移は成果にならず、読者の失望を生む。

### 0-3. 全体のCTA配置マップ

| # | セクション | 役割 | リンク先 | ボタンの重み |
|---|---|---|---|---|
| CTA① | S2 結論直下 | 急ぐ読者の即時遷移を拾う | `[A8商品リンク]` | 主 |
| CTA② | S5 比較表の直後 | 手段を選び終えた読者を拾う | `[A8商品リンク]` | 主 |
| CTA③ | S7 貸付条件表の直後 | **最重要地点**。条件に納得した読者を拾う | `[A8商品リンク]` | 主（最大） |
| CTA④ | S9 向き・不向きの直後 | 適合を自覚した読者を拾う | `[A8商品リンク]` | 主 |
| CTA⑤ | S12 まとめ直後 | 読み切った慎重層を拾う | `[A8商品リンク]` | 主 |
| 追従CTA | 全体 | S3以降でスマホ画面下部に固定表示 | `[A8商品リンク]` | 従（高さ56px以内） |

### 0-4. 全体で使う色・記号のルール（デザイナー向け）

- 情報の性質を色で統一する：**事実（グレー系の枠）／注意点（黄系の枠）／出典（小さい灰色文字）／CTA（ブランドのアクセント色）**
- 「※」で始まる注記はすべて本文より1段小さく、灰色にする
- 数値を強調する箇所は太字のみ。赤字と大きなフォントの多用は「怪しい広告」の印象を与えるため禁止
