# actwill-unsou: LP作成材料

- 公式参照URL: https://actwill.co.jp/lp5/unsou/a8/

- 想定検索意図: 運送業の法人経営者が、燃料費・車両費・人件費・入金サイトのずれ等による運転資金不足に対し、即時性のある調達手段を比較している。

## 競合横断で繰り返し現れる、使える構造

1. 運送業固有の支払いタイミングを最初に可視化する。
2. 読者が「自分が対象か」を初期に判断できるようにする。
3. 調達方法を一つだけ押し付けず、条件別に分岐させる。
4. 比較表は先に全体を見せ、詳細・注意点・申込の流れをその後に置く。
5. CTAはFV直下、比較後、条件確認後、ページ末の4地点で役割を変える。
6. 数値・認定・事例を置く場合、出典日と条件を隣接させる。

## 公式確認が必要な記事LPの事実欄

- アクト・ウィルの最新金利、融資額、返済方法・期間、代表者保証・担保の詳細
- 「最短60分審査」と「即日融資／即日契約」の正確な表現範囲
- 運送業限定の適用条件、必要書類、対象外条件
- 借入一本化の広告・本文での使用可否
- 比較対象に掲載する各方式の最新条件、評価基準、外部リンク
- PR表記、運営者情報、A8商品リンク、広告掲載URL提出
