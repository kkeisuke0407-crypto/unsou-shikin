- 作成日: 2026-08-05

## 1. 想定ユーザー

### 1-1. コアターゲット（記事の設計基準にする層）

| 項目 | 内容 |
|---|---|
| 立場 | 一般貨物自動車運送事業を営む**法人**の代表取締役、または資金繰りを任されている役員・経理責任者 |
| 規模 | 車両5〜50台程度、年商数千万円〜3億円程度、従業員10〜50名程度 |
| 業歴 | 3年以上（決算書が複数期ある） |
| 必要額 | 300万円〜3,000万円 |
| 使途 | 運転資金（燃料費・給与・社会保険料・車検整備費・税金）、車両の代替、突発的な修理、既存借入の返済原資 |
| 時間軸 | 「今月末」「来月10日」など**期日が決まっている**。1〜2週間以内に目処をつけたい |
| 金融リテラシー | 銀行融資の経験はある。ノンバンク、ファクタリング、リースバックの違いは正確には分かっていない |
| 現在の状況 | メインバンクに相談済み、あるいは相談を検討中。しかし時間がかかる／枠が埋まっている／断られた |
| 端末 | **スマートフォン70〜85%**（移動中・事務所・帰宅後の夜間に読む） |
| 読む時間帯 | 平日夜、早朝、土日が多い。電話受付時間外に読んでいる可能性が高い |

### 1-2. サブターゲット（受け止めるが、公式へは送らない層）

| 層 | 状態 | 記事での扱い |
|---|---|---|
| 個人事業主・軽貨物ドライバー | 法人ではない | 「対象は法人」と明示し、別手段（公庫、ファクタリング等）を案内して離脱させる |
| 必要額が300万円未満 | 最低融資額に届かない | 「300万円から」と明示し、別手段を案内 |
| 開業前・創業直後 | 決算書がない | 創業融資など別ルートがあることに触れる |
| 金利を最優先する層 | 時間に余裕がある | 公庫・銀行が先である旨を正直に書く |
| 情報収集のみ | まだ具体的な資金需要がない | 比較表と用語解説で価値を提供し、ブックマーク／再訪を狙う |

**方針**：サブターゲットを無理に公式へ送らない。**不適合な遷移はASPの成果にもならず、広告主の審査コストと読者の失望だけを生む。**「対象外」を明記することは、結果としてCV率とCV品質の両方を上げる。

## 2. ユーザーが抱えている悩み

### 2-1. 表層の悩み（本人が言語化できている）

1. 今月・来月の運転資金が足りない
2. 銀行に相談したが、回答まで時間がかかる／断られた
3. 車検・整備・修理の請求が重なった
4. 燃料費が上がったのに運賃が上がらない
5. ドライバーの給与・社会保険料の支払日が迫っている
6. 荷主からの入金が来月末で、それまでが持たない
7. 車両を代替しないと仕事が回らないが、資金がない

### 2-2. 深層の悩み（本人が言語化していない）

| 深層の悩み | 記事での対応 |
|---|---|
| **売上は増えているのに現金がない理由が分からない** | 「売上が増えるほど立替える運転資金も増える」という構造を、営業損益率1.0%・平均売上+8.0%というデータで説明する |
| **自社だけが苦しいのではないかという孤立感** | 営業赤字48%、車両10台以下では62%というデータで「構造的な問題」だと示す。ただし煽らない |
| **ノンバンクに手を出す＝経営が危ない、という自己認識への抵抗** | 「調達手段の使い分け」というフレームに置き換える。速さとコストのトレードオフとして説明する |
| **家族・従業員・取引先に知られたくない** | 来店不要・全国対応・電話営業なし・チャットボット申込という事実で応える |
| **騙されたくない、闇金だけは避けたい** | 金融庁DBでの登録確認手順を、読者が自分で再現できる形で提示する |
| **相談したら断りづらくなるのではないか** | 公式サイトが「弊社から電話営業を行うことはございません」と明示している事実を引用する |

### 2-3. 意思決定を止めている3つのブレーキ

| ブレーキ | 内容 | 解除する材料 |
|---|---|---|
| **信用ブレーキ** | 「この会社は本当に大丈夫か」 | 金融庁 登録貸金業者情報検索の突合結果（登録番号一致・更新日2026年3月20日・行政処分欄記載なし）、日本貸金業協会会員 第005834号、設立2013年、資本金5,500万円、主要取引銀行 |
| **条件ブレーキ** | 「自社が対象か、いくら借りられるか、返せるか」 | 融資対象＝法人、300万円〜1億円、実質年率3.00%〜15.00%、返済期間1ヶ月〜3年／1〜36回、返済額の目安表、代表者連帯保証は必要という正直な明示 |
| **手続きブレーキ** | 「何をすればいいのか、どれくらいかかるのか」 | 申込4STEP、チャットボット申込、仮審査最短60分、必要書類（代表者本人確認書類＋決算書類の一部）、書類はFAXまたは郵送、受取は振込または現金持参 |

## 3. 検索意図の分類

### 3-1. 主要検索クエリと、その裏にある意図

| クエリ群 | 検索意図の段階 | 読者が本当に知りたいこと | 記事のどこで答えるか |
|---|---|---|---|
| 運送業 資金調達／運送業 資金繰り | 手段探索（Awareness） | 「自分の状況で使える方法は何があるのか」 | 手段比較表（第4章） |
| 運送業 融資／運送会社 融資 | 手段特定（Consideration） | 「融資でいける？どこが貸してくれる？」 | 結論先出し＋比較表 |
| 運送業 ビジネスローン | 商品特定（Consideration） | 「ノンバンクの条件は？金利は？審査は？」 | 貸付条件表（第6章） |
| 運送業 運転資金／トラック 修理 資金 | 課題直結（Consideration） | 「期日に間に合うか」 | スピードの実態（第5・7章） |
| トラック 担保 融資／トラック リースバック | 代替手段（Consideration） | 「車を担保にできるのか」 | 比較表の「車両活用」行 |
| 運送業 ファクタリング | 代替手段（Consideration） | 「請求書で現金化できるのか」 | 比較表の「売掛債権」行 |
| アクト・ウィル 評判／アクトウィル 闇金 | 指名・信頼確認（Decision） | 「この会社は安全か」 | 信頼性セクション（第6章） |
| 運送業 融資 即日 | 緊急（Decision） | 「今日中にどうにかなるか」 | 「即日」の正確な意味（第7章） |
| ビジネスローン 審査 甘い／通らない | 不安（Decision） | 「自分は通るのか」 | 審査で見られる観点と準備（第7・9章） |

### 3-2. 検索面から読み取れる、書くべき／書くべきでないこと

**Googleの「関連する質問」に現れた実際の疑問**

- 「運送会社は儲からないのはなぜですか？」「運送業はやめた方がいいですか？」
  → 読者の一部は経営全体への不安を抱えている。**煽らず、構造として淡々と説明する**トーンが正解。「大変ですよね」と共感を売るより、データで「これは業界構造だ」と示すほうが法人代表者には刺さる。
- 「ビジネスローンの審査はゆるいですか？」
  → 審査への不安が強い。「通ります」と書けない以上、**「何を見られるか」「何を準備すればいいか」**で応答する。
- 「運転資金の調達にはどのような方法がありますか？」
  → 手段の整理そのものにニーズがある。比較表は必須。

**オーガニック上位の顔ぶれからの示唆**

- 上位は「資金調達方法7選」型のまとめ記事が占有。同じ形では勝てない。
- 記事LPの価値は「まとめ」ではなく、**「まとめを読んだあと、結局どうすればいいか」の1歩先**にある。
- アクト・ウィル自身も同キーワードでオーガニック上位にいるため、**公式サイトが書かない内容**（他手段との比較／向いていないケース／登録の確認方法／注意点）で差別化する。

## 4. 広告クリック後の心理プロセス（推奨する読了フロー）

PPC広告からの流入者は、平均して**最初の5秒**で「自分向けか」を判断し、**最初の30秒**で「読み続けるか」を決める。以下の6段階で設計する。

### Phase 1｜0〜5秒：ここは自分の場所か

- 心理：「運送業の融資って書いてあるけど、うちみたいな会社でも対象なのか」
- 必要：**業種（運送業）・対象（法人）・金額（300万円〜1億円）を一目で**
- 失敗パターン：会社の理念や長い前置きから始める／対象が分からない

### Phase 2｜5〜30秒：結論は何か

- 心理：「で、結局どこに相談すればいいの。ダラダラ読ませないでほしい」
- 必要：**冒頭で結論を出す。**「法人で300万円以上、期日が決まっているならビジネスローンが候補。その1社がアクト・ウィル」
- 失敗パターン：「まずは運送業の現状から見ていきましょう」と結論を後回しにする
- ここに**1本目のCTA**を置く。急ぐ読者を離脱させない

### Phase 3｜30秒〜2分：自分の状況は説明されているか

- 心理：「この記事、うちの事情を分かっているのか」
- 必要：運送業特有の資金の流れ（先に払い、後で受け取る）を**データ付きで**言語化する
- 効く材料：エネルギーコストの転嫁率48.9%、トラック運送は32業種中最下位圏、営業赤字48%、燃料費率13.5%、軽油166.7円（前年比+9.2%）、取適法後も支払期日は受領後60日以内
- ここで読者は「自分の判断は間違っていない」と確認する。**煽る必要はない。事実だけで足りる**

### Phase 4｜2〜4分：他の選択肢と比べてどうか

- 心理：「公庫や銀行、ファクタリングと比べてどうなの。損しないか」
- 必要：**中立な比較表**。公庫の基準利率（無担保 年3.60〜5.30%／2026年8月3日現在）まで出して、「金利だけなら公庫が有利」と正直に書く
- 決定打：「ただし、期日が動かせないなら、間に合わない選択肢は選択肢ではない」という一文
- ここに**2本目のCTA**

### Phase 5｜4〜7分：この会社は信用できるか／条件は納得できるか

- 心理：「聞いたことのない会社だ。闇金じゃないだろうな」「金利15%は高くないか」「保証人は？」
- 必要：
  1. 金融庁DBでの確認結果と、**読者が自分で確認する手順**
  2. 貸付条件の全項目（遅延損害金20.00%、印紙代、代表者連帯保証を含めて正直に）
  3. 「上限15.00%は利息制限法の法定上限と同水準」という**不利な情報の先出し**
  4. 「電話営業は行わない」という公式表明
- **不利な情報を先に出すほど、有利な情報の信頼度が上がる。** ここが記事全体の勝負どころ
- ここに**3本目のCTA（最重要）**

### Phase 6｜7分〜：自分は当てはまるか／次に何が起きるか

- 心理：「うちは当てはまるのか」「相談したら何が起きるのか」「断られたらどうなるのか」
- 必要：向いているケース／向いていないケースの明示、申込4STEPの具体、必要書類、チャットボット申込（電話では新規申込を受け付けていない）、平日9:00〜20:00
- ここに**4本目・5本目のCTA**
- 最後に「まずは相談だけ」という**最も軽い一歩**を提示する

## 5. 反論・懸念の一覧と、記事での回答

| 読者の心の声 | 記事での回答（根拠） | 掲載箇所 |
|---|---|---|
| 「聞いたことのない会社だ」 | 金融庁の登録貸金業者情報検索で1件ヒット。登録番号・代表者・所在地・電話番号が公式表記と一致。登録更新日2026年3月20日、行政処分欄の記載なし。日本貸金業協会会員 第005834号。2013年設立、資本金5,500万円 | 第6章 |
| 「闇金だったら怖い」 | 貸金業登録は3年ごとの更新制で、番号は自分で照会できる。確認手順を記事内に掲載 | 第6章 |
| 「金利15%は高い」 | 元本100万円以上の貸付における利息制限法の上限が年15%。3.00%が適用されるとは限らない。金利を最優先するなら公庫・銀行が先。それでも選ばれる理由は「間に合うこと」 | 第4・6章 |
| 「保証人を出せない」 | 第三者保証人・不動産担保は原則不要。ただし法人契約のため**代表者の連帯保証は必要**。一部の融資では担保を求められる場合もある | 第6章 |
| 「すでに借入がある」 | 事業性の法人向け貸付は総量規制（年収の3分の1）の対象外。ただし返済能力の審査はある | 第9章 |
| 「本当に即日で入るのか」 | 公式は「最短即日契約可能」としつつ「審査があるため即日実行できないこともある」と明記。急ぐ場合は午前中の申込が推奨されている | 第7章 |
| 「審査に通るのか」 | 通過を保証する記載はどこにもない。審査で見られるのは事業の継続性と返済能力。決算書類と資金使途を整理して相談する | 第7・9章 |
| 「相談したら営業電話が来るのでは」 | 公式サイトが「弊社から電話営業を行うことはございません」と明示。新規申込はチャットボットのみで、電話では受け付けていない | 第6・7章 |
| 「手数料を後から取られないか」 | 公式の貸付条件表では契約時締結費用は「印紙代（実費）」と記載。遅延した場合の遅れ損害金は年率20.00% | 第6章 |
| 「毎月いくら返すのか」 | 公式掲載の目安表を提示。ただし目安は下限金利に近い前提とみられるため、適用金利による差を編集部試算として併記 | 第6章 |
| 「取引先に知られないか」 | 来店不要・全国対応。ただし取引の内容は公式に確認すること（記事側で断定しない） | 第7章 |

## 6. トーン＆マナー

### 6-1. 守ること

- **法人代表者に向けた、対等な business-to-business の文体**。「あなたも今すぐ」のような煽り文体は使わない
- **結論 → 根拠 → 注意点** の順で書く
- 専門用語は初出時に一言で説明する（例：総量規制、ファクタリング、リースバック、遅延損害金）
- 数値には必ず出典と時点を添える
- 不利な情報を隠さない。むしろ先に出す
- 読者の状況を決めつけない（「経営が苦しいあなたへ」ではなく「支払期日が動かせない場面では」）

### 6-2. 使わない表現

| 使わない | 理由 |
|---|---|
| 「審査に通ります」「必ず借りられます」「100%」 | 保証表現。事実に反する |
| 「審査なし」「ブラックOK」 | 事実に反し、貸金業の広告として不適切 |
| 「必ず即日」「今日中に入金」 | 公式が否定している |
| 「低金利」（無条件） | 上限15.00%は法定上限と同水準 |
| 「業界No.1」「最安」「最適」 | 比較根拠がない |
| 「もう手遅れになる前に」「倒産する前に」 | 過剰な不安喚起 |
| 「銀行はもう頼りにならない」 | 他の調達手段を不当に貶める。読者の主要な選択肢を否定してはいけない |
| 他社の手数料・通過率・順位 | 検証していない |

### 6-3. 積極的に使う言い回し

- 「〜と公式サイトに記載されています」（出典を明示する）
- 「〜の場合は、別の方法のほうが合っている可能性があります」（正直さ）
- 「審査があるため、結果は保証されません」（誠実な留保）
- 「まずは条件が合うかどうかの確認から」（軽い一歩）
- 「金利だけで見れば〜が有利です。ただし〜」（対比による納得）

## 7. CTAの心理設計

| # | 位置 | 読者の状態 | 心理的ハードル | 訴求すべき言葉 |
|---|---|---|---|---|
| 1 | 結論直下 | 急いでいる／すでに手段を決めている | 低 | 条件を「確認する」（申し込むではない） |
| 2 | 手段比較の直後 | ビジネスローンで進むと決めた | 中 | 「ビジネスローンの条件を見る」 |
| 3 | 貸付条件表の直後 | 条件に納得した／最も熱量が高い | 中 | 「無料相談で自社の条件を確認する」 |
| 4 | 向き・不向きの直後 | 自分が対象だと確認できた | 低〜中 | 「対象に当てはまるか確認する」 |
| 5 | 記事末 | 慎重に読み切った | 低 | 「まずは相談だけしてみる」 |

**共通のマイクロコピー方針**

- ボタン直前に必ず「相談は無料」「電話営業は行われないと公式に明記」「申込は公式サイトのチャットから」のいずれかを置く
- ボタン文言に「申込」を使うのは4番目以降のみ。前半は「確認する」で統一し、心理的ハードルを下げる
- ボタン下に小さく「※審査があります。結果を保証するものではありません」を添える（信頼性の担保）
