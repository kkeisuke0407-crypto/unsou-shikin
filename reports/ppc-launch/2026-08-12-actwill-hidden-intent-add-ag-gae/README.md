# アクト・ウィル｜共通探索CPへ資金イベントAGを追加するGAE

これは**新規キャンペーンを作らない**追加用パッケージです。

既存の `共通探索CP` に、資金イベント探索の4広告グループだけを加えます。初期予算が小さいため、CPを分けずに一つのCP内で検索語句・クリック・MCVを比較する構成に修正しました。

## 追加する広告グループ

- `AG04 傭車・協力会社支払`
- `AG05 受注増・入金ギャップ`
- `AG06 車両導入・リース否決`
- `AG07 事故・稼働復旧`

追加内容は、34キーワード（原則完全一致、`傭車費`のみフレーズ併用）、RSA 4本、既存除外KWと重複しない追加除外17件です。

## 取込み順

1. `01_GAE_ADD_ADGROUPS_UTF16.csv`
2. `02_GAE_ADD_KEYWORDS_UTF16.csv`
3. `03_GAE_ADD_RSA_UTF16.csv`
4. `04_GAE_ADD_CAMPAIGN_NEGATIVES_UTF16.csv`

`共通探索CP` の既存サイトリンク・コールアウトはそのまま使うため、重複して追加しない。

プレビューでは、新規キャンペーンが作成されず、`共通探索CP` に上記4AGだけが追加されることを確認してから投稿する。

> 先に作成した `GAE_アクトウィル_資金イベント探索CP_2026-08-12` はCPを分けすぎた旧版なので、使用しない。
