# アクト・ウィル｜資金イベント探索CP GAE取込みパッケージ

既存の `共通探索CP` は変更せず、今回の検索意図調査で見つけた「融資をまだ直接検索していないが、法人運送会社の資金需要が高い」語だけを分離した**新規キャンペーン**です。

## 作成内容

- 新規キャンペーン名: `運送資金_資金イベント探索CP_20260812`
- 状態: **一時停止**（インポート後も配信されません）
- 検索ネットワーク: Google検索のみ / 検索パートナーOFF / AI Max OFF
- 入札: 個別の手動CPC、初期上限 **50円**
- 日予算: **2,000円**（7日間14,000円のテスト枠）
- 地域・言語: 日本 / 日本語
- マッチタイプ: 原則完全一致。`傭車費` のみ関連語を確認するためフレーズ一致を併用。
- 広告グループ: 4件
- キーワード: 34件
- キャンペーン除外KW: 35件
- サイトリンク: 5件、コールアウト: 7件

## 4つの探索テーマ

|広告グループ|狙う状況|選定理由|
|---|---|---|
|AG01 傭車・協力会社支払|傭車費・外注費を先に支払う|`傭車費` はKWPで月間100〜1,000、競合性低。運送業らしさと仕事がある兆候が強い。|
|AG02 受注増・入金ギャップ|大口受注・繁忙期・荷主入金待ち|事業が動いており、運転資金が先に必要になる状況を拾う。|
|AG03 車両導入・リース否決|増車、頭金不足、ローン／リース審査後|車両導入は300万円級になりやすいが、個人・販売意図を完全一致で抑える。|
|AG04 事故・稼働復旧|事故、保険金待ち、修理・買替|稼働継続に必要な事業資金を探す法人に限定して検証する。|
