# アクト・ウィル運送業案件｜PPCキーワード調査・選定

- 作成日: 2026-08-12（JST）
- 対象: アクト・ウィルの法人・運送事業者向け事業資金案件
- 成果地点: 新規の法人がWEB申込み/問い合わせ後30日以内に簡単審査（仮査定）を完了
- 出稿方針: 商標は対象外。低CPCを目的化せず、法人運送会社率・資金イベント・300万円以上期待・審査健全度を優先する。

## 結論

**現時点のKWP実測だけでは、法人運送会社×高資金需要だけで月3,000〜5,000検索を作れるとは確認できない。**

既存のKWP実測が付いたS/A語の安全側合計は **約280検索/月**。これは語句間の重複を控除していない上限寄りの足し算であり、広告の実インプレッション見込みではない。今回の候補母集団は **723語**（S 0 / A 342 / B 286 / C 76 / 除外 19）まで拡張したが、702語はKWP未調査であり、検索数をゼロとも有望とも判定していない。

したがって、初回の正しいゴールは「3,000〜5,000という数を作る」ではなく、**傭車・協力会社支払、車両導入否決、受注増の先行資金、入金ギャップ**をKWPで一括展開して、法人性を維持した実測母数を積むこと。量が出ても修理店・中古販売・求人・用語説明が主体なら採用しない。

## 調査方法と情報源

1. 国土交通省・全日本トラック協会の運送原価・資金繰り資料で、燃料油脂・修繕・タイヤ・車両リース/減価償却・保険・人件費・高速料金・傭車費が資金需要になり得ることを確認。
2. NEXCO東日本のETCコーポレートカード案内で、カード利用料金が後払い請求となることを確認。
3. 既存のKWP CSV（2026-08-11）とKWP初回観測（2026-08-12）を読み込み、実測レンジ・競合性・上部掲載単価は判明分だけ転記。
4. 上記の業界語と資金不足イベントを自然な検索文へ展開し、KWP再投入用の候補群を作成。

## 初期戦略と初日の推奨KW数

1. **Google広告へ即時に一括追加はしない。** `03_INITIAL_TEST_KW.csv` はS/Aから116語を選んだ候補表で、KWP未調査語は先にKWPで確認する。
2. 初日は、既存の配信語と重複しない **40〜60語の完全一致**を推奨。テーマは「傭車・協力会社」「車両否決」「受注増・入金前」を分け、広告文もテーマ別にする。
3. 入札は原則50円。KWP低額帯が50円を超える語は、勝手に上げず `50円テスト対象外` として保留する。
4. 最初の判断はクリックではなく、検索語句の法人性→仮査定導線のMCV→成果確定で行う。

**初期出稿候補116語のうち、KWP実測がある語だけの安全側検索数合計は約120検索/月。** これは3,000〜5,000に遠く、未調査語に勝手な検索数を足して埋めていない。次のKWP一括調査で、候補 723語をテーマごとに展開し、S/Aだけの実測検索母数を再集計してから増枠判断する。

## 次に追加調査する領域

1. `傭車`/`庸車`の地域・業態別関連語（冷凍、一般貨物、幹線、地場、スポット便）をKWPの関連候補から拾う。
2. 燃料カード・ETCコーポレートカードのブランドを除いた支払・引落・限度額語を関連候補で拡張する。
3. 車両ローン/リースは「法人」「事業用」「運送会社」を付け、販売店・個人購入を検索語句レポートで除外する。
4. 受注増・増便・新規路線は運送特有の語を足し、実際に検索される自然文だけを残す。
5. 3,000〜5,000を目標にするときも、説明語・求人・修理店・個人購入を混ぜない。実測で届かなければ、この案件では高意図だけの母数上限として受け入れる。
