## 表現上の禁止事項

記事LP・広告文の双方に適用する。

| 禁止 | 理由 |
|---|---|
| 「審査に通ります」「必ず」「確実」「100%」 | 保証表現 |
| 「審査なし」「ブラックOK」 | 事実に反し、貸金業の広告として不適切 |
| 「必ず即日」「今日中に入金」 | 公式サイトが「即日融資実行ができないこともある」と明記 |
| 「低金利」（無条件） | 上限15.00%は元本100万円以上の利息制限法上限と同水準 |
| 「無担保」「無保証」の断定 | 代表者の連帯保証が必要 |
| 広告文でのブランド語（社名・サービス名） | ASPのリスティング制限が「社名・サービス名以外」 |
| 広告文での貸金業登録番号 | 広告コピーでの権威付けには使わない方針 |
| 他社の手数料率・通過率・順位 | 未検証 |
| 競合ページの文言・事例・画像 | 転載不可 |
